# mforesti/tap

Homebrew formulae for gee, the CLI for Gravitee Cloud and Gravitee APIM.

```sh
brew tap mforesti/tap
brew trust mforesti/tap     # Homebrew 7 only loads trusted taps' formulae
brew install mforesti/tap/gee
```

`Formula/gee.rb` is regenerated by gee's release workflow for every release
(`scripts/brew-formula.sh` in mforesti/gee): do not edit it by hand. The
archives are downloaded from the public package
[ghcr.io/mforesti/gee](https://github.com/users/mforesti/packages/container/package/gee).
